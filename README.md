# ✈️ AI-Powered Trip Planner

An **AI-powered trip planning web application** that helps users create personalized travel plans based on their preferences, budget, duration, and interests. The app uses modern web technologies and AI to deliver smart, dynamic, and user-friendly trip recommendations.

---

## 🚀 Features

- 🧠 **AI-generated trip plans** based on user requirements  
- 🔐 **Authentication & user management** using Clerk  
- 🗺️ Personalized itineraries (destinations, activities, duration, budget, etc.)  
- ⚡ Fast, modern UI built with **Next.js**  
- 🗄️ Real-time backend powered by **Convex**  
- 🤖 AI integration using **OpenAI Router**  
- ☁️ Secure and scalable architecture  

---

## 🛠️ Tech Stack

- **Frontend:** Next.js (App Router)
- **Backend / Database:** Convex
- **Authentication:** Clerk
- **AI:** OpenAI (via OpenAI Router)
- **Package Manager:** npm
